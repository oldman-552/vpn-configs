# إدارة صور الإعلانات المتناوبة (`promo/`)

يعرض تطبيق **bahrain-vpn** نافذة إعلان منبثقة فور فتح البرنامج تتناوب تلقائيًا بين الصور المفعّلة (`1 -> 2 -> 3 -> 4 -> 5 -> 1`) مع عدّاد إغلاق (`3` ثوانٍ ثم زر `✕`)، دون الحاجة لإعادة بناء ملف الـ APK.

## كيفية تغيير الصور في أي وقت
1. استبدل أي ملف من الملفات الخمسة (`ad1.png` إلى `ad5.png`) بصورتك الجديدة بنفس الاسم، أو ارفع صورة بصيغة `.jpg` / `.png` / `.webp` وحدّث حقل `"image"` المقابل في `ads.json`.
2. يكتشف التطبيق تغيّر الصورة تلقائيًا عبر `ETag` ويحدّث النسخة المحفوظة على هواتف المستخدمين.

## إعدادات ملف `ads.json`
- `"enabled"`: `true` لتفعيل نظام الإعلانات، أو `false` لإيقافه بالكامل عن جميع المستخدمين فورًا.
- `"close_delay_sec"`: عدد الثواني قبل تفعيل زر الإغلاق `✕` (الافتراضي: `3`).
- داخل كل عنصر في `"ads"`:
  - `"enabled"`: لتفعيل أو إخفاء صورة معينة بشكل مستقل.
  - `"image"`: اسم ملف الصورة داخل مجلد `promo/` (مثل `"ad1.png"` أو `"ad1.jpg"`).
  - `"title"` *(اختياري)*: نص قصير يظهر أسفل الصورة.
  - `"link"` *(اختياري)*: رابط يبدأ بـ `https://` يفتح عند الضغط على الإعلان أو الزر (اتركه `""` إذا كانت الصورة للعرض فقط).
  - `"button_text"` *(اختياري)*: نص الزر عند وجود رابط (مثل `"تواصل معنا"` أو `"اشترك الآن"`).
