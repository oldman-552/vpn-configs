# PRIVACY.md — Privacy Policy & Data Handling Architecture

## 1. Zero Traffic Logging & Zero Browsing Telemetry
`bahrain-vpn` (`com.bahrain.vpnconfigs`) and its Pure-GitHub backend **never collect, inspect, store, or transmit**:
- Visited domains, URLs, DNS queries, or browsing history
- Application payload contents, messages, or credentials
- Client real IP addresses on any backend server

The Explicit URL Probe tool in the Android Diagnostics screen tests **only** the single URL explicitly typed by the user on demand and stores nothing remotely.

---

## 2. Public Nodes vs Attested Private `VIP 💎` Nodes
Our platform enforces strict separation between **Transport Security** and **Operator Privacy**:
- **Public Community Configs (`Privacy: Unverified` or `High Risk`)**: Aggregated from public Telegram and GitHub sources. Even when TLS 1.3 or Reality is cryptographically verified (`Security: Verified`), the exit server operator is an unverified third party (`Privacy: Unverified`). Configs disabling certificate verification (`allowInsecure=1`) or lacking encryption are marked `Privacy: High Risk` or quarantined.
- **Private `VIP 💎` Configs (`Privacy: Verified`)**: Provisioned by your platform administrator inside the AES-256-GCM encrypted enterprise vault (`vip_nodes_enc_b64`), unlocked exclusively in memory for authenticated subscribers, and blocked from clipboard/file export.

---

## 3. Local Device Storage & Optional Redacted Diagnostics
- **On-Device Preferences (`SharedPreferences` / App Files)**: Stores selected server, custom imported configs, split-tunnel package list, local speed test history, and pseudonymous `inst_*` installation ID (used solely for local license device-limit verification against the signed `bundle.json`).
- **Diagnostic Export (`Consent-Only`)**: Disabled by default (`diagnosticConsent = false`). Even when enabled by the user, `AppDiag.redactSecrets()` strips UUIDs, passwords, tokens, Reality keys, and repository paths before copying technical metrics (startup time, memory usage, crash count) to the clipboard.

---

## 4. Public Statistics API Redaction
All public `/api/v1/*` artifacts generated by `public_api.py` automatically strip raw proxy URIs, UUIDs, passwords, Reality keys, and query secrets, and mask endpoint IP octets (`203.0.xxx.xxx`) and middle domain labels (`ed***.example.com`).
